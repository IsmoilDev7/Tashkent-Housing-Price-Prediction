# 🏠 Tashkent Housing Price Prediction

## 📌 Project Overview

This project focuses on predicting housing prices in Tashkent using machine learning techniques. The goal is to analyze real estate data and build a predictive model that estimates property prices based on various features.

## 🎯 Objective

To develop an accurate regression model that can predict house prices and support data-driven decision-making in the real estate market.

---

## 📊 Dataset

The dataset includes key housing features such as:

* Location (district)
* Number of rooms
* Area (square meters)
* Floor and total floors
* Building type
* Price (target variable)

---

## ⚙️ Technologies Used

* Python (Pandas, NumPy, Scikit-learn)
* Jupyter Notebook / Google Colab
* Matplotlib / Seaborn
* SQL (optional)
* Power BI (for visualization)

---

## 🔄 Project Workflow

### 1️⃣ Data Collection

* Collected housing data from local sources (Tashkent real estate listings)

### 2️⃣ Data Cleaning

* Handled missing values
* Removed outliers
* Standardized formats

### 3️⃣ Exploratory Data Analysis (EDA)

* Analyzed price distribution
* Explored relationships between features
* Visualized trends

### 4️⃣ Feature Engineering

* Encoded categorical variables (location, building type)
* Created new features (price per m²)

### 5️⃣ Model Building

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

### 6️⃣ Model Evaluation

* RMSE (Root Mean Squared Error)
* MAE (Mean Absolute Error)
* R² Score
